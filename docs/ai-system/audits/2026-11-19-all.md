## 진단에서 문제가 없던 것

- order-service: `@Transactional` 안의 Feign 호출 없음, `KafkaTemplate` 직접 사용은 outbox 릴레이뿐
- product-service: Kafka 발행은 모두 커밋 후(`@TransactionalEventListener`), 상품 검색에 N+1 없음
- user-service: JWT 발급/검증, `logout.lua`, 토큰 비교
- 서비스 간: Lua 키/인자 순서, Feign 요청/응답 필드, 토픽 상수와 메시지 키가 양쪽에서 일치
